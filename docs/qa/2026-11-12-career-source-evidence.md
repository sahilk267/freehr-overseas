# Grounded CV career evidence and chronology review

Date: 12 November 2026 (Asia/Calcutta). Scope: M14-F03/F04/F06 connected to existing matching, candidate screening, privacy and owner UI. The complete advanced roadmap remains open.

## Behavior

- The existing `parse_cv` free-model route can return bounded employment, education, certification and explicitly stated skill records alongside its compatible legacy output. Every record names one literal source quotation. The server checks exact, unambiguous UTF-16 text spans, literal title/organization/date support, explicit current-role markers and prohibited recruitment signals. Unsupported records remain visible for owner review and are excluded from grounded inference. Model confidence describes extraction; it does not establish employment or credential authenticity.
- The worker binds its extracted text, scanned file hash, current document generation, candidate, extractor version, model and observation date. A mismatched candidate/document pair, superseded or altered source, withdrawn processing permission, suppression or a late result after source correction cannot replace current evidence. Source-integrity hashes survive MySQL JSON key reordering. Provider-supplied server provenance is discarded.
- English month names and explicit ISO year/month/day formats are parsed deterministically. Year-only evidence keeps a month interval. Ambiguous numeric formats, unsupported language/date formats, reversed and future dates remain clarification issues. Current employment is anchored to its observation month. Coverage combines interval unions, distinguishes minimum/maximum month coverage, and never certifies exact tenure or relevant years. There is no assumed career start, inferred personal gap reason, age, protected-trait scoring or automatic rejection.
- Definite intermediate gaps and overlapping employment ranges generate neutral review questions. Overlap can represent legitimate concurrent/project work. Differing dates for the same role across current CVs remain visible rather than silently selecting one source. Education/certification dates and credential validity are not invented.
- The owner can check a literal source statement, request clarification, exclude a record or record an explanation of eligible chronology questions. Unsupported/reversed/future facts cannot be certified through an explanation. Each command binds current candidate fingerprint, source signature and review revision. Exact retries reuse a receipt; stale competing edits fail. Exclusion updates inference/coverage while preserving the historical record.
- A source-entry correction also provides a bounded fallback when free-model parsing is unavailable. It re-reads the private clean CV and checks its actual scanned SHA-256 before saving grounded records. File objects are preserved. Successful literal extraction cancels unused parsing jobs; an older in-flight provider failure cannot downgrade the recovered source. The existing document-change ledger invalidates matches and old candidate questionnaires. Correction/review notes and quotations are included in candidate erasure. No second candidate, profile, matching, consent or scheduling authority is introduced.
- New grounded matching context uses supported, non-excluded skill statements; uncited legacy skill summaries and guessed model experience years are not promoted when grounded evidence exists. Bounded inference summaries retain source references and explicitly unverified semantics. Canonical fresh owner-recorded candidate evidence remains authoritative. Career gap/overlap questions do not reduce retrieval priority or authorize a disposition.
- New candidate questionnaires reuse the existing private review, response, clarification and shared follow-up lifecycle. A bounded set of unresolved chronology questions is included, with role-entry references. Gap questions are optional owner context, not automatic requests for personal explanations. Existing candidate self-report identity limits remain unchanged.
- Owner Candidates now includes a responsive career source panel with exact quotations, uncertainty, combined employment month coverage, source conflicts, versioned review and literal correction controls. Failed mutations preserve input and require current-source reload instead of overwriting a concurrent edit.
